# Clozera web app

TanStack Start application (React 19, TypeScript 7) with shadcn/ui on Base UI and
Tailwind CSS v4. See [doc/architecture.md](../doc/architecture.md) for how data,
routing and state are split.

## Development

```sh
npm run dev      # http://localhost:5173, proxies /api to API_INTERNAL_URL (default http://localhost:3000)
npm run build    # SSR server in dist/server, assets in dist/client
npm start        # serve the production build with srvx
```

## Validation

```sh
npm run typecheck
npm run check    # Oxfmt + type-aware Oxlint, including @shadcn/lint and jsx-a11y
npm test
```

## Conventions

- File routes live in `src/routes`; `routeTree.gen.ts` is generated by the build and dev server.
- The signed-in area (`src/routes/_app`) renders on the client only because it uses
  TanStack DB collections. Public pages render on the server.
- Server data: TanStack Query (`src/data/session.ts`, `src/data/languages.ts`) and
  TanStack DB (`src/data/collections.ts`). Do not copy server data into Zustand.
- Zustand (`src/stores/preferences.ts`) only stores per-device preferences.
- Shareable navigation state belongs in validated search params.
- Forms use `useAppForm` from `src/components/form.tsx` with schemas from `@clozera/shared`.
- Add UI primitives with `npx shadcn@latest add <component>`; `components.json` uses the
  Base UI `base-vega` style. Theme tokens are in `src/styles.css`.

See [the shared UI and practice standards](../doc/frontend-ui.md).
